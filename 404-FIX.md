# 404 Troubleshooting Guide

## The Issue

You're getting 404 errors when accessing API endpoints. This is a **Next.js routing issue**.

## Root Cause

Next.js is **case-sensitive** about API routes:
- ✅ **Must be**: `pages/api/` (lowercase)
- ❌ **Won't work**: `pages/API/` (uppercase)

Your original project had `pages/API/` (uppercase) which Next.js cannot route to.

---

## Solution Applied

I've renamed the directory structure in the fixed version:
```
pages/API/     →  pages/api/     (lowercase)
```

## Understanding Next.js API Routes

Next.js automatically creates routes based on file structure:

```
pages/api/vm/vms.js        →  http://localhost:3000/api/vm/vms
pages/api/vm/deploy.js     →  http://localhost:3000/api/vm/deploy  
pages/api/auth/login.js    →  http://localhost:3000/api/auth/login

pages/API/vm/vms.js        →  DOES NOT ROUTE (wrong case!)
```

The folder **must** be lowercase `api/` for Next.js to recognize it.

## Quick Verification Script

Save as `verify-setup.sh`:

```bash
#!/bin/bash

echo "Narrekappe VM Deployer - Setup Verification"
echo "==========================================="
echo ""

# Check 1: Directory structure
echo -n "1. Checking directory structure... "
if [ -d "/root/Narrekappe-BV-main/pages/api" ]; then
    echo "✓ (lowercase api/ found)"
elif [ -d "/root/Narrekappe-BV-main/pages/API" ]; then
    echo "✗ (uppercase API/ found - needs fixing)"
    echo "   Run: cd /root/Narrekappe-BV-main/pages && mv API api"
else
    echo "✗ (api directory not found)"
fi

# Check 2: Service running
echo -n "2. Checking if service is running... "
if systemctl is-active --quiet narrekappe-vm-deployer; then
    echo "✓"
else
    echo "✗"
    echo "   Run: systemctl start narrekappe-vm-deployer"
fi

# Check 3: Port listening
echo -n "3. Checking if port 3000 is listening... "
if netstat -tlnp 2>/dev/null | grep -q ":3000"; then
    echo "✓"
else
    echo "✗"
fi

# Check 4: API endpoint responding
echo -n "4. Testing API endpoint... "
RESPONSE=$(curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/api/vm/vms 2>/dev/null)
if [ "$RESPONSE" = "200" ]; then
    echo "✓"
elif [ "$RESPONSE" = "404" ]; then
    echo "✗ (404 - check directory structure)"
else
    echo "✗ (HTTP $RESPONSE)"
fi

echo ""
echo "==========================================="
```

Run with:
```bash
chmod +x verify-setup.sh
./verify-setup.sh
```
